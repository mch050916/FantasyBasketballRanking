02
Punt Planner
Ranks which categories a roster is already losing most, and re-ranks the full player pool with one category's weight zeroed.
python scripts/punt_planner.py --team "YourTeam"
03
Trade Finder
Searches every 1-for-1 swap in the league for trades that improve both sides' expected categories won per week.
python scripts/find_trades.py --team "YourTeam"
04
Buy Low / Sell High
Diffs real in-season per-game performance against each player's preseason projection, weighted the same way the model values categories.
python scripts/buy_low_sell_high.py
