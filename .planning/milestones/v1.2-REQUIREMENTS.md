## v1.2 Requirements

### Category Balance Diagnostics

- [x] **CBAL-01**: User can see which category groups are still over- or under-driving the biggest exact-league 14-cat misses.
- [x] **CBAL-02**: User can compare category-balance changes against saved exact-league baselines instead of judging them from intuition.

### Category Calibration

- [x] **CCAL-01**: User can recalibrate category influence across multiple distortion families without rewriting the core DURANT pipeline.
- [x] **CCAL-02**: User can keep exact-league 14-cat snapshots as the primary acceptance surface while still checking Yahoo-style outputs as secondary sanity checks.
- [x] **CCAL-03**: User can rerun the full ranking and validation loop after category-balance changes and see whether the distortion pattern improved.
